Repair old self-copies
A message you put your own address on used to file itself under Sent and never reach the inbox here, because both copies carry one Message-ID. New mail lands correctly; this goes back over the old ones, checks each against your inbox at iCloud, and moves what is really there.
Backup
—
Every night at 03:17 UTC the database — accounts, folders, read and star state, contacts, blocked senders, settings — is copied into your own storage. Message bodies are already there. Restore only adds back rows that have gone missing; nothing that exists now is changed.
Remote images
A remote image is fetched from the sender's server as the message opens, which tells them you read it and when. Asking first, the default, holds them back behind the Images button. Either way, nothing is re-downloaded when you switch — the blocked form is what has always been stored.

Model
Write reply, Fix spelling and Improve in the composer send that message to Anthropic's Claude API, and this is the key and the model they use. Select some text first and only that is rewritten. The key is checked with Anthropic before it is kept, sealed in the database like the iCloud password, and never shown again — only its last four characters. Test asks Anthropic what this key can actually reach; the menu only offers what came back.

Keep recent mail on this device
Off by default, and set for this device alone. When it is on, this device keeps the first page of each folder as you last saw it, the text of the messages you open, and the newest in your inbox, so they stay readable without a connection. They are stored in this browser, readable by anyone who can use it, and the oldest go first once the copy passes 400 items or 30 MB. Attachments are never kept. Nothing you change is queued: offline, archive, delete, star, move and send say they need a connection and do nothing. Signing out, a session that has ended, or switching this off removes the copy from this device.

Also under More on a phone. A rule sorts their mail as it arrives: into a folder, a category, starred, read or pinned.
Blocking destroys their mail at iCloud as it arrives: nothing is stored here, nothing is counted, and no notification fires. Everything they have already sent goes with it. There is no undo.
Blocked senders
Mail from these is expunged at iCloud on the sync that finds it, so it never reaches this app at all. The count is the only trace kept — without it, a rule that has quietly stopped matching looks exactly like one that is working.
Rules
Each new message in the inbox is checked against these in order. Moving, starring and marking read are done at iCloud, so every device agrees; categories and pins are kept here. Mail that was already here is left alone until you run the rules.

Contacts
What the composer suggests: the people saved in People, then anyone you have sent mail to. Removing one only hides the address from suggestions here — it changes no card and nothing at your provider.
Import and export
Bring old mail in from .eml and .mbox files, or take a folder out as one .mbox. Imported mail is written to your mailbox at iCloud, so it shows on every device.
Import mail
An .eml message or an .mbox archive, as many as you like. Thunderbird’s own mailbox files have no extension and work too.
Into folder
Messages already in your account, found by their Message-ID, are skipped, so a file can be run again after a failure without making copies. One message is up to 25 MB.
Export a folder
Every message in the folder, with its read and starred state, in one file. To export only some, choose them in the list and use the export button in the bar.
